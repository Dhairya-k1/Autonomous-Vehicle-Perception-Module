# Autonomous Vehicle Perception Module

## 🚘 Project Overview
This project implements an autonomous driving perception subsystem integrated with the CARLA Simulator. It focuses on real-time lane detection, lane keep assistance, and dynamic object awareness. The primary goal is to provide robust environmental perception, enabling an intelligent vehicle to safely navigate urban environments by monitoring surroundings, adjusting speed, and performing appropriate lane changes in response to nearby vehicles and obstacles.

## ✨ Key Features
* Real-time Lane Detection: Detects lane markings accurately under varying urban driving conditions.
* Lane Keeping Assist (LKA): Provides continuous lateral guidance to keep the vehicle centred within its lane.
* Dynamic Object Awareness: Detects and tracks surrounding vehicles, pedestrians, and obstacles.
* CARLA Simulator Integration: Fully integrated testing environment for real-time sensor feedback and control loops.

## 🛠️ Tech Stack & Requirements
* Simulation: CARLA Simulator
* Language: Python
* Environment: Jupyter Notebook (`.ipynb`)
